# Code signing policy / Política de firma de código

**English**

Free code signing provided by [SignPath.io](https://about.signpath.io), certificate by [SignPath Foundation](https://signpath.org).

- **What is signed:** the Windows installer of Coach LoL IA (`Coach-LoL-IA-Setup-<version>.exe`) published in [GitHub Releases](https://github.com/pepeipto/coach-lol-ia/releases).
- **How it is built:** every release is built from the source code of its git tag by the [Release workflow](.github/workflows/release.yml) on GitHub Actions. Nothing built on a personal computer is signed.
- **Team and roles:**
  - Committer and reviewer: [Carlos Fernandez Medina (@pepeipto)](https://github.com/pepeipto)
  - Approver (approves every signing request manually in SignPath): [Carlos Fernandez Medina (@pepeipto)](https://github.com/pepeipto)
- All team members use multi-factor authentication on GitHub and SignPath.
- **Privacy:** this program does not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it. The data it sends, and how to turn each feature off, is described in the [privacy policy](https://www.coachlolia.com/privacidad) and shown during installation.
- **Uninstall:** Windows Settings → Apps → Coach LoL IA → Uninstall.
- **License:** [MIT](LICENSE).

**Español**

Firma de código gratuita de [SignPath.io](https://about.signpath.io), certificado de [SignPath Foundation](https://signpath.org).

- **Qué se firma:** el instalador de Windows de Coach LoL IA (`Coach-LoL-IA-Setup-<versión>.exe`) que se publica en [GitHub Releases](https://github.com/pepeipto/coach-lol-ia/releases).
- **Cómo se compila:** cada versión se compila desde el código de su etiqueta de git con el [workflow Release](.github/workflows/release.yml) de GitHub Actions. Nunca se firma nada compilado en un ordenador personal.
- **Equipo y funciones:** Carlos Fernandez Medina ([@pepeipto](https://github.com/pepeipto)) escribe, revisa y aprueba a mano cada solicitud de firma en SignPath.
- Todo el equipo usa verificación en dos pasos en GitHub y en SignPath.
- **Privacidad:** el programa solo envía datos a otros sistemas cuando lo pide quien lo usa. Qué se envía y cómo desactivar cada función está en la [política de privacidad](https://www.coachlolia.com/privacidad) y se muestra al instalar.
- **Desinstalar:** Configuración de Windows → Aplicaciones → Coach LoL IA → Desinstalar.
- **Licencia:** [MIT](LICENSE).
