# 🐞 Cómo informar de un problema

Abre **una publicación por problema**, elige una etiqueta y copia esta plantilla:

```
Versión de la app: (Ajustes → Acerca de, p. ej. 3.6.0)
Windows: (10 u 11)
Qué ha pasado:
Qué esperabas que pasara:
Cómo repetirlo: 1) ... 2) ... 3) ...
¿En qué momento?: (cliente / selección de campeón / carga / partida)
Modo de ventana de LoL: (Sin bordes / Pantalla completa)
```
Adjunta una captura o un vídeo si puedes. **Tapa tu Riot ID** y cualquier dato personal si no quieres que se vea.

Cuando esté arreglado, el equipo pondrá la etiqueta ✅ Resuelto y la versión que lo arregla.

# 🐞 How to report a bug

Open **one post per problem**, pick a tag and fill in: app version (Settings → About), Windows 10/11, what happened, what you expected, steps to reproduce, when it happened (client / champ select / loading / in game) and LoL window mode. Screenshots or videos help a lot; hide your Riot ID if you prefer. Fixed posts get the ✅ tag with the version that fixes it.
